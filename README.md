# НейроПроха 🌿

Дружелюбный Telegram-бот на базе Deepseek-R1 и использованием бесплатного api от io.net!

## Возможности бота
- Ответы в стиле «ботанического сада»
- Поддержка команд `/start`, `/faq`
- Админ-рассылка через `/send` (только для владельца)

## Руководство по запуску
1. Установите зависимости: `pip install python-telegram-bot httpx`
2. Измените `config.json` под ваши данные (api и бот-токен)
3. Запустите: `python bot.py`
